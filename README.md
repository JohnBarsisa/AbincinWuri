# AbincinWuri — Expo Mobile Starter

**Status: early mobile app scaffold.** The current repository is a minimal React Native/Expo starter, not a completed food-ordering product.

## Current implementation

- A simple `App.js` component using React Native primitives.
- An Expo project configuration and starter assets.
- A JavaScript-based cross-platform starting point for Android, iOS and web development.

## Run it

```bash
git clone https://github.com/JohnBarsisa/AbincinWuri.git
cd AbincinWuri
npm install
npm start
```

This code uses **Expo SDK 45 / React Native 0.68**. Modern Expo Go or Node versions may require migration to run it.

## Product direction (not implemented yet)

AbincinWuri could evolve into a local food discovery and ordering experience with merchant listings, menus, carts, checkout and delivery status. These are **ideas for future work**, not current repository features.
